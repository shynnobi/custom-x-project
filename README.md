# Custom X Project
 
Custom X Project is a 3D web experience that lets you view Mega Man and customize his look in real time.
 
Live demo: https://custom-x-project.netlify.app
 
## Features
- **3D viewer** powered by Three.js (via React Three Fiber)
- **Customization** (colors and parts)
- **Animations** and camera controls
 
## Tech Stack
- React + TypeScript + Vite
- @react-three/fiber / drei / postprocessing
- Zustand
- TailwindCSS
 
## Getting Started
Prerequisites: Node.js + pnpm
 
```bash
pnpm install
pnpm dev
```

pnpm dev
